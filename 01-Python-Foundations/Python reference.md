# Python environment creation

<u>**Using Conda**</u>

conda create -p venv python==3.12

**<u>For Conda activate**</u>

conda activate venv/ <name of the enivronment>

<u>**Using Python**</u>

python -m venv myenv

<u>**Activate**</u>

naviagate to myenv/Scripts/activate

<u>**Using virtualenv**</u>

pip install virtualenv (install virtual env)

virtualenv -p python3 virtual_env (Created virtual environment)

naviagate to virtual_env/Scripts/activate

To deactivae all the environment could be same path provide deactivate

**To install ipykernal in jupyter**

pip install ipykernel
